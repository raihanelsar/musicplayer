# 🎵 Music Player

A simple web-based music player with interactive UI, built with HTML, CSS, and JavaScript.

---

## 🔧 Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## ✨ Features

- Play / pause lagu  
- Navigasi antar track  
- Tampilan antar muka yang responsif  
- Mendukung file audio lokal (dari folder `media`)
